### ***Описание***
Данный код выполняет тестирование сайта https://edujira.ifellow.ru/ на следующий функционал:
>*- Авторизация пользователя;* \
>*- Открытие основной страницы;* \
>*- Открытие проекта TEST;* \
>*- Счёт количества заданий проекта;* \
>*- Правильность состояния статуса и версии одного из заданий;* \
>*- Создание баг репортов и их закрытие до готовности.*

А также форматирует отчёт тестов с помощью allure.
