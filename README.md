### ***Описание***
Данный код выполняет тестирование сайта https://edujira.ifellow.ru/ на следующий функционал:
>*- Проверка авторизация;* \
>*- Проверка открытия основной страницы;* \
>*- Проверка открытия проекта TEST;* \
>*- Проверка счётчиков количества заданий проекта;* \
>*- Проверка правильного состояния статуса и версии одного из заданий;* \
>*- Проверка функционала создания баг репортов и их закрытие до готовности.*

А также форматирует отчёт тестов с помощью allure.
