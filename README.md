### ***Описание***
Данный код выполняет тестирование на следующий функционал: 
>Функция: Тестирование отправки POST-запросов на сервер Reqres с использованием JSON-файло\
>>Получение тестовых данных из файла potato.json \
>>Валидация значения по ключу name (ожидается "potato") \
>>Модификация данных: 
>>>Обновление значения name на "Tomato" \
>>>Добавление значения "Eat maket" для ключа job \
>>Проверка, что модифицированные данные отличаются от исходных \
>>Отправка POST-запроса с обновлёнными данными на сервер 

>Функция: Тестирование обработки данных персонажей из вселенной Rick & Morty
>>Получение данных персонажа с ID = 2 
>>>Проверка имени персонажа (ожидается "Morty Smith") \
>>>Анализ эпизодов появления персонажа: \
>>>Проверка последнего эпизода (ожидается "S05E10") \
>>Получение данных о последнем персонаже этого эпизода \
>>>Проверка имени (ожидается "Young Jerry") \
>>Определение текущей локации персонажа 
>>>Проверка локации (ожидается "Earth (Unknown dimension)") \
>>Сравнительный анализ характеристик: 
>>>Сравнение расы и местонахождения исходного и полученного персонажей 
        
Технологии: 
>Язык тестов: Gherkin (русская локализация) \
>Фреймворк: Behave или аналогичный BDD-инструмент \
>Система отчетности: Allure или аналогичная
